## 🗣️ Målsvar att kunna utantill inför examinationen

När mappen är klar ska du kunna återge dessa med egna ord:

> **Commit:** "En commit är en sparad ögonblicksbild av projektet med ett meddelande om vad som ändrats. Den blir en punkt i historiken."

> **Synlig medverkan:** "I Exam 1 ska det synas i GitHub-historiken att alla i gruppen kodat. Jobbar ni på samma dator skriver ni namnen i commit-meddelandet — annars syns bara den som är inloggad i Git."

> **Metoden:** "Har jag en liten, begriplig ändring? Då: git add de filerna, git commit med tydligt meddelande (+ namn om par), sedan git push så GitHub får dem."

## 📝 Examination

**Examination 1 (Eventsidan)** versionshanteras i ett **gemensamt GitHub-repo**. Det ska synas i commit-historiken att alla i gruppen kodat. Samma dator → skriv namnen i meddelandet. Inlämning = länk till repot i Moodle.
