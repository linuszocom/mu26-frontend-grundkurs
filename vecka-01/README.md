## 🗣️ Målsvar att kunna utantill inför examinationen

När veckan är klar ska du kunna återge dessa två principer med egna ord:

> **Semantik:** "Semantisk HTML betyder att vi väljer taggar efter vad innehållet betyder — t.ex. header för sidhuvud — så strukturen blir tydlig för människor och verktyg. Det är bättre än bara div överallt, för div säger ingenting om betydelsen."

> **Metoden:** "Jag frågar först vad innehållet är, sedan väljer jag en tagg som betyder samma sak. Om jag bara tänker 'låda' stannar jag — då är risken div."
