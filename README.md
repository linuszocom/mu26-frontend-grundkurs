# 📖 Så använder du detta GitHub-repo för dina studier

Välkommen till din **digitala kursbok** för kursen *Grundläggande Frontend-programmering*[cite: 3]. 

Detta repository innehåller alla teoriguider, visuella modeller, kodövningar, AI-granskningsuppgifter och självtester du behöver under kursens gång[cite: 22, 23, 24, 25, 26].

---

## 🛑 Grundprincip: Du behöver INTE ladda ner detta repo

Ett vanligt missförstånd bland nya studenter är att man måste "klona", "forka" eller ladda ner hela detta repository till sin dator. **Det behöver du inte göra!**[cite: 27]

* **Läs direkt i webbläsaren:** Detta repo är en webbsida[cite: 27]. Du klickar bara på mapparna och filerna här på GitHub precis som i en digital bok[cite: 27].
* **Koda på din egen dator:** När du gör övningarna skapar du egna mappar och filer lokalt i VS Code på din dator[cite: 5, 24]. Det är din *egen* kod du sparar och senare versionshanterar i dina *egna* repon på GitHub[cite: 6, 28].

## 🎯 Välj ditt studiespår (Hur pluggar du idag?)

Du anpassar hur du använder GitHub utifrån din studiesituation:

### 🟢 Spår 1: Du var med live på Teams-lektionen (13:00–16:00)
1. Öppna veckans mapp (t.ex. `vecka-35/`)[cite: 27].
2. Gå direkt till **`03-ovningar.md`** och koda uppgifterna i VS Code[cite: 24, 27].
3. Gör **`04-ai-traning.md`** för att stärka ditt kodägarskap[cite: 25, 27].
4. Testa dig själv i **`05-sjalvtest.md`** utan att titta på facit först[cite: 26, 27].
*(Använd `01-teoriguide.md` som uppslagsverk endast om du kör fast[cite: 22, 27].)*

### 🟡 Spår 2: Du missade lektionen eller var sjuk (Ta ikapp-spåret)
1. Börja från start: Läs **`01-teoriguide.md`** från topp till tå[cite: 22, 27].
2. Titta på **`02-visuell.md`** för att förstå mentalmodellen och strukturen[cite: 23, 27].
3. Koda alla uppgifter i **`03-ovningar.md`**[cite: 24, 27].
4. Gör **`04-ai-traning.md`** och stäm av i **`05-sjalvtest.md`**[cite: 25, 26, 27].

### 🟣 Spår 3: Du siktar på VG / Vill fördjupa dig (Stretch)
1. Gör de markerade *Stretch-uppgifterna* längst ner i `03-ovningar.md`[cite: 24, 27].
2. Skriv en egen `README.md` i dina övningsmappar där du dokumenterar och motiverar dina arkitektur- och kodval[cite: 27].

## 🤖 AI som studiepartner (Real Talk)

Det är tillåtet och bra att använda AI (som ChatGPT eller Google Gemini) som ett bollplank under dina självstudier[cite: 1, 2]:

* **Använd AI som hjälplärare:** Fråga *"Vad betyder den här felkoden?"* eller *"Förklara skillnaden mellan padding och margin i min kod"*[cite: 7].
* **Kopiera aldrig blint:** Du måste alltid förstå varje enskild rad du klistrar in i ditt projekt[cite: 1, 2]. Kan du inte förklara koden muntligt under examinationen räknas det som bristande ägarskap och kan leda till underkänt betyg[cite: 1, 2].
* **Styr AI:n – låt inte AI:n styra dig:** Ju mer du tränar med hjälp av detta studentmaterial, desto tryggare blir du i att veta hur lösningen ska se ut[cite: 22, 28].
